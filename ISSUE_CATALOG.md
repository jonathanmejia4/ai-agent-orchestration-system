## How to Use This Catalog

1. **Hunters** create issues in `issues/{LANE}/{LANE}-NN.md`
2. **Fixers** find open issues from this catalog
3. **Sync tool** keeps stats accurate: `python3 tools/sync_catalog_stats.py`

## Invoking Agents

```bash
# Hunt all lanes in parallel
@IH-Orchestrator Run ALL

# Fix all lanes in parallel
@IF-Orchestrator Run ALL

# Hunt specific lanes
@IH-Orchestrator Run lanes D, E, G
```
