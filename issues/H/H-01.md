## Problem Description

- **What is wrong:** `ISSUE_CATALOG.md` has a "Lane Definitions" table (lines 16-45) that jumps straight from Lane A to Lane C — **Lane B has no definition row**. But in the "Lane Completion Status" table below (lines 52-78) Lane B appears with a "Verified: 1" count, and `.claude/agents/issue-hunters/IH-Lane-B.md` exists ("Half-Baked Fix Scanner"). So the catalog documents the lane's existence twice while leaving its definition blank.
- **Expected:** Every lane that has a hunter/fixer agent and appears in the Completion Status table should also have a row in the Lane Definitions table describing its specialization.
- **Actual:** The Lane Definitions table is missing Lane B entirely.
- **Scope:** `ISSUE_CATALOG.md`. A stranger browsing the catalog sees "Lane B" stats with no clue what Lane B is for.
