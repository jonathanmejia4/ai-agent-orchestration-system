# [LANE W] Issue W-01: No test suite exists for tools/

- Type Tags: W-Issue, Missing-Tests, Quality
- Severity: 6/10 (MEDIUM)
- Status: OPEN
- Date Discovered: 2026-04-23

---

## Problem Description

- **What is wrong:** The repo ships 247 Python tools in `tools/` plus a full orchestration framework, but has **no `tests/` directory and no pytest suite**. `requirements.txt` does not list `pytest` or any test framework. There is zero automated verification that any tool actually works.
- **Expected:** A `tests/` directory with at least smoke tests for the core issue-management tools (`add_issue.py`, `sync_catalog_stats.py`, `issue_stats.py`, `verify_issue.py`).
- **Actual:** `ls tests/` returns "No such file or directory". `requirements.txt` contains only `pyyaml`.
- **Scope:** Every tool in `tools/`. The framework markets itself as "production-grade" but has no test coverage to back that claim.

## Evidence

```bash
$ ls tests/ 2>&1
ls: tests/: No such file or directory

$ cat requirements.txt
pyyaml

$ find . -name "test_*.py" -o -name "*_test.py" 2>/dev/null | head -5
# (no matches — zero test files anywhere in the repo)

$ ls tools/*.py | wc -l
247
```

- **Source:** repository root — `tests/` directory absent, no pytest files exist

## Fix Requirements (DO NOT IMPLEMENT)

- [ ] Create `tests/` directory at repo root
- [ ] Add `pytest` to `requirements.txt`
- [ ] Add at least one smoke test (e.g. `tests/test_add_issue.py`) that exercises the issue lifecycle end-to-end
- [ ] Ensure new test imports the tool via subprocess or direct import without relying on network or secrets

## Verification Commands

```bash
# Check 1: tests/ directory exists
test -d tests && echo "PASS" || echo "FAIL"

# Check 2: At least one test_*.py file exists
ls tests/test_*.py 2>/dev/null | head -1 | grep -q . && echo "PASS" || echo "FAIL"

# Check 3: pytest listed in requirements.txt
grep -qi "pytest" requirements.txt && echo "PASS" || echo "FAIL"

# Check 4: Tests actually run and pass
(cd tests && python3 -m pytest -q 2>&1 | tail -3) || echo "FAIL"
```
