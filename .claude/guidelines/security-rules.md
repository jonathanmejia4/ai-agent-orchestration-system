# Security Guidelines

> Define YOUR project's security rules here.

## Never Commit

<!-- Example:
- API keys
- Passwords
- .env files with real values
- Private keys
-->

## Always Validate

<!-- Example:
- User input (sanitize everything)
- File uploads (check type/size)
- URLs (whitelist domains)
-->

## Forbidden Patterns

<!-- Example:
- eval() or exec()
- SQL string concatenation
- Hardcoded passwords
- innerHTML without sanitization
-->

## Access Control

<!-- Example:
- Check permissions before actions
- Use principle of least privilege
- Log access to sensitive data
-->
