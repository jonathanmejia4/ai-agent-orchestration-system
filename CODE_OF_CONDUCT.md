# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

## Summary

We want this project to be a welcoming, professional space for contributors of all backgrounds and experience levels. Be respectful, be constructive, assume good faith.

## Expected Behavior

- Be kind and considerate in discussions and code review.
- Give constructive feedback; accept it gracefully when offered.
- Take responsibility for mistakes; apologize when appropriate; learn.
- Focus on what is best for users of the framework and the broader community.
- Respect differing viewpoints and experiences.

## Unacceptable Behavior

- Personal attacks, insulting comments, or derogatory language.
- Harassment of any kind.
- Publishing others' private information without permission.
- Any conduct that a reasonable person would consider inappropriate in a professional setting.

## Reporting

If you experience or witness behavior that violates this code of conduct, please open a GitHub issue with the `code-of-conduct` label, or contact the project maintainer privately via the email listed in `git log` for recent commits.

Reports will be reviewed and investigated promptly and fairly. Project maintainers are obligated to respect the privacy and security of the reporter.

## Enforcement

Maintainers may take any action they deem appropriate, including:

1. **Correction** — a private warning with an explanation.
2. **Warning** — a formal warning with consequences for continued behavior.
3. **Temporary ban** — removal from project spaces for a defined period.
4. **Permanent ban** — permanent removal from the project.
